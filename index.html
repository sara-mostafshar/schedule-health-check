What should my Excel file look like?

Sheet "Activities": Activity ID, Activity Name, Activity Type (Task / Start Milestone / Finish Milestone / Level of Effort), Status, Original Duration (d), Remaining Duration (d), Start, Finish, Actual Start, Actual Finish, Baseline Start, Baseline Finish, Total Float (d), Constraint Type, Constraint Date, Budgeted Cost.

Sheet "Relationships": Predecessor ID, Successor ID, Relationship Type (FS/SS/FF/SF), Lag (d).

Durations and float in working days. Put the data date in a cell labelled Data Date (e.g. on a "Read Me" sheet), or set it above. Common Primavera P6 / MS Project export names are recognised too.
