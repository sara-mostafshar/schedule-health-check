What should my Excel file look like?

Sheet "Activities": Activity ID, Activity Name, Activity Type (Task / Start Milestone / Finish Milestone / Level of Effort), Status, Original Duration (d), Remaining Duration (d), Start, Finish, Actual Start, Actual Finish, Baseline Start, Baseline Finish, Total Float (d), Constraint Type, Constraint Date, Budgeted Cost.

Sheet "Relationships": Predecessor ID, Successor ID, Relationship Type (FS/SS/FF/SF), Lag (d).

Durations and float in working days. Put the data date in a cell labelled Data Date (e.g. on a "Read Me" sheet), or set it above. Common Primavera P6 / MS Project export names are recognised too.

From MS Project: export the task table to Excel with ID, Name, Duration, Start, Finish, Actual Start, Actual Finish, Baseline Start, Baseline Finish, Total Slack, Constraint Type, Constraint Date, Resource Names, Predecessors and Summary. Text such as "5 days" or "3FS+2 days" is read automatically and summary tasks are skipped. Add a cell labelled Status Date or set the data date above. See the MS Project sample for the layout.

Other tools or a plain Excel plan: use the P6 / Excel template – its "Read Me" sheet explains each step. Columns you don't have (float, baseline, cost) can stay empty: those checks show N/A instead of a false pass or fail. N/A checks do not count as passed, so missing data lowers the score – it means incomplete data, not a worse schedule.

Health score
Score = checks passed (12+ healthy, 8–11 needs attention, below 8 not reliable). N/A checks (missing data) do not count as passed. My rule of thumb – DCMA itself gives no overall score.
